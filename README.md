Hotel Booking Data Cleaning – Python Mini Project
Project Overview

This project focuses on cleaning and preparing hotel booking data using Python. The aim is to transform raw data into a clean, structured, and analysis-ready format that can be used for further exploratory analysis or modeling. The project highlights practical data preprocessing skills that are commonly required in data analyst roles.

Dataset Description
Dataset: Hotel Booking Demand
File: hotel_bookings.csv
Format: CSV

The dataset contains booking-level information such as the number of adults, children, and babies, along with other hotel-related attributes.

Data Cleaning Steps

The following preprocessing steps were performed:
Renamed columns for better readability and consistency
adults →  num_adults
children → num_children
babies → num_babies
Identified and handled missing values
Standardized column naming conventions
Prepared the dataset for downstream analysis
